# Task 1 — Dev / Cybersecurity / Web3

Pick **one** track and complete it. See `task-1-problem-statement.pdf` in this folder for full requirements.

## 1. Tracks (summary)

**Development — To-Do List**
Build a working To-Do app (frontend-only or full-stack) with add / edit / delete / mark complete, plus clear pending vs completed view. Frontend-only → `localStorage`. Full-stack → DB + backend.

**Cybersecurity — Basic Web Recon**
Recon an authorized training target only (e.g. TryHackMe). Nmap scans, DevTools inspection, headers/cookies/`robots.txt`/endpoints. Document 3+ observations + why they matter + remediation.

**Web3 — Simple Smart Contract**
Solidity contract storing a number/message with setter + getter. Deploy + test in Remix, show value changing.

## 2. Mandatory submission rules (all tracks)

1. **Folder with your name:** create your folder inside `Task-1/` as:
   ```
   Task-1/Firstname-Lastname/
   ```
   Example: `Task-1/Adil-Bains/`. Put all your code + your own README + screenshots inside it.

2. **Video of the outcome (mandatory for everyone):** record a **2–5 min screen recording** showing your work running and explain what you did.
   - Dev: demo the app working
   - Cyber: walk through commands + findings
   - Web3: show deploy + interact changing the value
   - Upload to Drive/YouTube (unlisted/public) and put the link in your folder README.

3. **Fork + PR:**
   - Fork this repo → add your `Firstname-Lastname` folder → commit → open a Pull Request to `main`.
   - PR title: `Task-1: Firstname-Lastname - <Track>`
   - PR description must contain: track, tech used, deployment link (if any), video link.

4. **Deployment link (if possible):**
   - Dev: Vercel / Netlify / Render etc. if possible, otherwise just video + code is fine.
   - Cyber: no deployment — include recon output/screenshots + report README.
   - Web3: Remix share / testnet explorer link if possible, otherwise screenshots + video is fine.

Minimum per track:
| Track | Minimum deliverable |
|---|---|
| Dev | Working app + README + demo video (+ deployment link if possible) |
| Cyber | Recon evidence + README report + demo video |
| Web3 | `.sol` contract + README + demo video/screenshots (+ deployment link if possible) |

## 3. Your folder README must include

- Name + track
- Approach (what you built / how)
- Setup / run steps (or commands used for Cyber, deploy steps for Web3)
- Deployment link (if any)
- Video link
